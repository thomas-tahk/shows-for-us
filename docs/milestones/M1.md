## How to try it

On your Mac, from the repo:

```
git fetch && git checkout m1-flagships
cd frontend && npm ci && npm run dev
```

Open http://localhost:5173 (and try it on your phone at the network URL Vite prints). Then:
1. Type "hamil" in **Search shows** and pick Hamilton.
2. Read **Created by**, **History** and **Original cast**.
3. **Playing next**: locally there's no `/api` server, so it says live dates are unavailable and shows **Official tickets**. Click it; it opens hamiltonmusical.com in a new tab.
4. Open a show without an official link, e.g. Rent. You get **Search Ticketmaster for Rent** instead.
5. Spot-check the write-ups: open each show and compare against its Wikipedia article. Files are in `frontend/content/shows/<slug>.yaml`; `frontend/content/README.md` explains how to mark one checked.

Or skip the local setup and open the PR's Vercel preview on your phone: https://shows-for-us-git-m1-flagships-thomas-tahks-projects.vercel.app. Real live dates need the key added there (your steps below).

Watch for:
- The amber **Draft** box on every show page. It disappears per show once you set `status: owner-checked` and `sources_opened: true`.
- No show photo and no "From Wikipedia" summary yet. They're hidden on purpose until the first live data pull, because today's `data/shows.json` is built from hand-made test fixtures.
- The footer credits (Wikidata, Wikipedia CC BY-SA 4.0, and the Ticketmaster notice).

3. **First live data pull**, after merging to main: Actions → "Refresh data" → Run workflow. It pulls all 15 shows from Wikidata and Wikipedia and opens a `data-refresh` PR. Or locally run `cd frontend && npm run pull` (plain, never `--record`). If any show fails, the run goes red and names the show; the likeliest causes are a wrong Wikipedia title in `frontend/data/flagships.json` or a show whose Wikidata item isn't classed as a musical (the log prints its classes).
4. **Live Ticketmaster check:** on the deployed site open `/show/hamilton` and confirm real dates appear, then try a touring show. Also open `/api/events?show=hamilton`, which should return JSON.
5. On the deployed Hamilton page, check that the **IBDB** link opens Hamilton's IBDB show page. The URL format was taken from a wiki template and is unverified.
